
# vulpes

a minimal shell written in rust.

> work in progress

## quick start

```bash
cargo build --release

./target/release/vulpes
```

## builtins so far

| command | description 	|
|---------|-------------	|
| `cd`    | change directory|
| `exit`  | exit shell		|
